# Allura Beauty Care

Projet de site e-commerce beauté réalisé en HTML et CSS.

## Fichiers
- `index.html` : structure de la page.
- `style.css` : styles, mise en page, animations et responsive.

## Images
Les chemins d'images dans le code sont des chemins locaux. Pour afficher les images, ajoute les fichiers correspondants à la racine du dépôt :
- `WhatsApp Image 2026-11-19 at 18.43.13.jpeg`
- `P_tales de roses rouges en suspension.png`

Les images des produits seront ajoutées lorsque le catalogue sera défini.

## Ouvrir le projet
Ouvre `index.html` dans un navigateur, ou utilise l'extension Live Server de Visual Studio Code.
